# SEO basics

Search engines reward pages that answer what someone typed. Start there.

**Per page**
- One topic per page. Decide the phrase a customer would actually type ("emergency plumber Tampa", not "plumbing solutions").
- `<title>`: that phrase plus the business name, under 60 characters. Unique on every page.
- Meta description: one plain sentence saying what they get, under 155 characters.
- One `h1` that matches what the page is about. Subheadings as `h2`.
- Say the specific things in the text: services, prices or ranges, areas served, hours. Real words customers search for.
- Images: descriptive file names and `alt` text. Compressed so the page loads fast.
- Links between related pages using words that describe the target, not "click here".

**Technical**
- Works on a phone and loads quickly. Slow pages rank worse and lose visitors.
- HTTPS. One canonical URL per page. A `sitemap.xml` and a sane `robots.txt`.
- Add `LocalBusiness` or relevant schema.org JSON-LD with the true name, address, phone and hours.

**Local**
- Claim the Google Business Profile and keep name, address and phone identical everywhere.
- Real reviews matter. Ask real customers.
- A page per main service, and per area only if you can write something true and different for each.

**Do not**
- Stuff keywords, hide text, buy links or write filler pages. It reads badly and gets penalized.
- Promise a ranking. Nobody can.
